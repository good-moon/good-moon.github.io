Yomi サポート

Yomi は、日本語の本を正しい読みで聴くための読み上げリーダーです（iPhone・iPad・Mac）。

お問い合わせ

不具合、ご要望、ご質問は dev@goodmoon.io までお送りください。お使いの端末と OS のバージョン、Yomi のバージョン、使っている音声サービスを添えていただけると助かります。本の内容や API キーは送らないでください。

よくある質問

無料で使えますか？
Apple の声はそのまま無料で使えます。クラウドの音声サービスは、ご自身でそのサービスの API キーを取得して設定します（料金はそのサービスに直接お支払いいただきます）。

どんな本が読めますか？
EPUB、テキスト、Markdown、青空文庫の本です。DRM 付きの本には対応していません。

購入を復元するには？
設定 → Yomi Pro → 「購入を復元」を押してください。同じ Apple アカウントの iPhone・iPad・Mac で使えます（ファミリー共有にも対応）。

読み方が違うときは？
読み方の辞書（本ごと・全体）に登録すると、その読みで読み上げます。

プライバシーポリシー

Yomi Support

Yomi is a reader for listening to Japanese books with the readings right, on iPhone, iPad and Mac.

Contact

For bugs, requests or questions, email dev@goodmoon.io. Please include your device and OS version, the Yomi version and the voice service you use. Please don't send book text or API keys.

FAQ

Is it free?
Apple voices work free out of the box. For cloud voice services, you get your own API key from that service and pay it directly.

What books can I read?
EPUB, text, Markdown and Aozora Bunko books. Books with DRM are not supported.

How do I restore my purchase?
Settings → Yomi Pro → Restore Purchases. It works on iPhone, iPad and Mac with the same Apple Account, and with Family Sharing.

A word is read wrong.
Add it to the reading dictionary (per book or for everything) and Yomi will use that reading.
